# Журнал изменений и решений проекта

Этот файл — единый реестр всего, что происходило с проектом «Elena Gallery»:
что просили, что сделали (или почему не сделали), в какой ветке/коммите
это лежит. Цель: чтобы в новой сессии не нужно было перечитывать всю
переписку — достаточно открыть этот файл и найти нужный фрагмент.

Как пользоваться:
- Новые записи добавляются **сверху** (последняя — первой).
- Каждая запись — по шаблону ниже.
- Если задача не выполнена (например, не хватает доступа/репозитория),
  это тоже фиксируется — со статусом и причиной, чтобы не поднимать
  вопрос заново с нуля.

Шаблон записи:

```
## YYYY-MM-DD — Краткий заголовок

- Запрос: что попросил пользователь (своими словами, коротко)
- Статус: Сделано / Не сделано / Частично / Нужно уточнение
- Что сделано: конкретные изменения (файлы, коммиты, ветки)
- Комментарий: важный контекст, ограничения, причины, если что-то
  не сделано
```
