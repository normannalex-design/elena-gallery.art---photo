# Журнал изменений и решений проекта

Этот файл — реестр всего, что происходило именно с этим репозиторием
(хранилище фото). Цель: чтобы в новой сессии не нужно было перечитывать
всю переписку — достаточно открыть этот файл и найти нужный фрагмент.

**Связанный файл:** реальный код сайта живёт в репозитории
[`normannalex-design/art`](https://github.com/normannalex-design/art),
там ведётся свой `CHANGELOG.md` со всеми правками вёрстки/стилей/кода.
Этот репозиторий (`elena-gallery.art---photo`) — только хранилище фото,
к которому сайт из `art` обращается через GitHub API. Архитектурные
решения, касающиеся связи двух репозиториев, дублируются в обоих
файлах.

Как пользоваться:
- Новые записи добавляются **сверху** (последняя — первой).
- Каждая запись — по шаблону ниже.
- Если задача не выполнена (например, не хватает доступа/репозитория),
  это тоже фиксируется — со статусом и причиной, чтобы не поднимать
  вопрос заново с нуля.

Шаблон записи:

```
## YYYY-MM-DD — Краткий заголовок

- Запрос: что попросил пользователь (своими словами, коротко)
- Статус: Сделано / Не сделано / Частично / Нужно уточнение
- Что сделано: конкретные изменения (файлы, коммиты, ветки)
- Комментарий: важный контекст, ограничения, причины, если что-то
  не сделано
```
